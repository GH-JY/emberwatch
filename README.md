Emberwatch is a seven-night survival game: keep a signal fire alive on a dark moor, gather wood before the flames die, and hold the shades off with a lantern beam and a flare.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
